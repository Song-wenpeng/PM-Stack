# PM Stack 评论助手 · 0.1.0

这是 Edge / Chrome 的 Manifest V3 扩展。它使用安装所在浏览器配置的 Amazon 登录状态，采集指定商品最新一页评论，并传回本机 PM Stack。没有读取 Cookie、密码或浏览器配置文件的功能。

## 第一次安装（Edge）

1. 打开你日常使用、已登录 Amazon 的 Edge 用户配置。
2. 在地址栏输入 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本 `browser-extension` 文件夹（里面应有 manifest.json）。不要选择它的上级目录或 ZIP 文件。
4. 打开新版 PM Stack，进入“评论分析 → 采集与云端 → 评论采集”。
5. 点击“连接扩展 / 复制连接码”。
6. 在 Edge 右上角扩展菜单打开“PM Stack 评论助手”，粘贴连接码，点击“保存并连接”。

Chrome 的安装入口为 `chrome://extensions`。浏览器管理策略不允许加载未打包扩展时，需要管理员允许或后续发布商店版本，应用不会绕过浏览器策略。

## 采集

1. 在 PM Stack 的“评论采集”页，选择“日常浏览器 · 复用登录”后输入一个商品链接或 ASIN，选择对应的 Amazon 站点。
2. 点击“采集最新一页”。扩展会定期检查任务（通常约 30 秒，浏览器休眠时可能延迟）；点击扩展的“立即检查任务”可立即领取。
3. 扩展会在同一浏览器配置内新建评论标签页。登录失效或出现验证码时，在此标签页完成操作，然后点击扩展的“登录后继续”。
4. PM Stack 显示新增和重复条数后，到“评论库”刷新查看。评论已按现有规则去重，并进入现有待同步队列；此入口不会主动上传云端。

连接码保存在本机，正常重启无需重新粘贴。每次打开 PM Stack 仍需启动连接。一次只连接一个浏览器配置；切换配置前，在旧扩展里断开，再在 PM Stack 断开并重新连接。

## 范围

- 第一版每次一个商品、最新一页、最多 100 个已识别评论卡片；不是全量评论采集。
- 不支持自动翻页、按星级遍历、批量商品或绕过登录/验证码。
- 页面没有可识别评论时显示错误，不把空白页面当作采集成功。
- 取消后不会保存迟到结果，已经打开的标签页会保留。
- 可以关闭扩展弹窗，但需要保持浏览器及 PM Stack 运行。
- 修改扩展代码后在扩展管理页点击“重新加载”。不要移动已经加载的扩展文件夹。

## 数据权限

权限仅包括支持的 Amazon 站点页面访问、本机 127.0.0.1 通信、扩展自身设置和定时检查任务。没有 cookies、debugger、历史记录或全部网站权限。

本地连接仅监听 127.0.0.1:18765，校验扩展来源和随机连接码；普通网页无法提交任务或评论。连接码只在本机保存，请勿分享。
