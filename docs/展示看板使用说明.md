# 展示看板（v1.11.4）

展示看板是 PM Stack 的第五个模块，可用 Ctrl+5 打开。数据在本地计算，不需要 AI 服务。

## 直接导入日常研究工作簿

点击“导入工作簿”，选择包含商品主表、历史销量和历史销额的 `.xlsx` / `.xlsm`。程序自动识别并生成看板，不需要选择模板或转换表格。

- 商品主表：例如 `Product-US-Last-30-days`，包括 ASIN、品牌、插孔数、线长、包装数、颜色、三级分类、USB、打标、分类等特征。
- 历史销量：`ASIN` 为行标识，`2024-04` 等月份为列，值为该 ASIN 当月销量。
- 历史销额：使用相同的 ASIN 和月份结构，值为当月销额。
- 程序按 ASIN 关联这三张表，不按行位置拼接。字段提取日志等辅助子表不参与统计。
- 优先从 `Product-US-...` 等表名识别站点，并据站点设置币种（US 对应 USD）。无法唯一识别时会弹出来源调整窗口。
- 初始显示最近 12 个月，可通过起止月份选择完整历史范围。统计来自历史子表，主表的最近 30 天销量/销额不会替代历史数据。

原工作簿始终只读。程序兼容以前的 ASIN×月份明细格式，但不再要求用户先选择两种格式。

## 使用商品特征筛选

点击“添加属性筛选”，勾选一个或多个属性后，会在顶部增加与月份、品牌相同样式的常驻下拉框；可以继续添加其他属性。下拉框内支持搜索、多选和应用，列表上方固定“全选”开关，底部“全部 / 不限”可恢复不限制该属性；标题旁的 × 可移除属性框。“重置筛选”保留已添加的框。本机记住常用属性布局，重新导入同类表格后恢复。

要按指定商品分析，在“添加属性筛选”中搜索并勾选“ASIN”，添加后展开 ASIN 下拉框，搜索并勾选一个或多个商品编号，再点“应用”。所选 ASIN 会与其他属性条件取交集，同时更新指标卡、趋势、份额、商品明细、导出和矩阵发送范围。份额分母也以筛选后的商品样本计算。点击“全部 / 不限”、重置筛选或移除 ASIN 筛选框可取消限制。重新加载数据源保留仍存在的 ASIN，已不存在的选值会移除并提示。商品明细页的文字搜索仍只影响明细，不改变看板统计。

属性列表优先展示插孔数、线长、包装数、颜色、三级分类、USB、打标、分类、插孔方向等主表字段。同一字段多选取并集，不同字段取交集。例如“打标=1、插孔数=3”，会同时筛选对应商品及其全部所选历史月份。

数字型属性按自然整数显示，例如 1.0 显示为 1。没有提取到特征的商品显示“未指定”，不自动剔除，也不推测属性。主表字段按当前快照应用于历史月份，不能据此还原过去的产品特征变更。

“关注品牌”控制指标卡和商品明细，市场分母保留当前月份、站点、品类、属性和价格筛选范围。“排名维度”可选择品牌或产品特征，“统计指标”可切换销量和销售额。

市场趋势图高度提高，默认按全部可见曲线的数据范围调整纵轴；非零起点会明确提示。可开启“从零开始”对照绝对量级，或点击“放大查看”打开独立大图。放大图仍可点击月份定位明细，缺失值保留断点。

图表可悬停查看数值，点击品牌、属性分组或月份可定位商品明细。明细支持搜索、数值排序和多行选择，并优先展示商品特征。明细搜索和图表定位不改变市场分母。

商品明细可选择单元格，按 Ctrl+C 复制选中内容；Ctrl+A 选中当前明细全部单元格。右键可复制鼠标所在单元格、选中内容或所选整行，复制的多行多列可直接粘贴到 Excel。点击左侧行号可选择整行，Ctrl/Shift 可多选。发送矩阵时，若选择了单元格，则使用这些单元格所在的商品记录。

有效 ASIN 显示为带下划线的链接，单击使用系统默认浏览器打开该行站点的亚马逊商品页，例如 US 对应 amazon.com，UK/GB 对应 amazon.co.uk。Ctrl/Shift 点击用于选择，拖动选择不会打开链接。未知站点或非标准 ASIN 保留普通文本，可照常复制。

顶部不再单列币种选择，按导入来源保留统计币种；同一站点包含多个币种时，站点选项会标明币种，分别统计。样本范围显示在底部汇总说明下方。

月份、品牌和其他下拉框使用高度受限的搜索面板；“全部月份”“全部”和属性“全选”固定在列表外，不随列表滚动。小窗口的筛选区可滚动，导出和矩阵按钮保留在底部。

## 工作簿更新后重新加载

先在 Excel/WPS 中保存文件，再点右上角“重新加载数据源”。程序重新读取当前文件，保留有效的品牌、品类、属性、价格和分组设置；无需重新选择文件或保存方案。结束月份原本为最新月份时，自动跟随新增月份；手动选择的历史截止月继续保留。

新数据已删除的属性或选值会清除，并在底部提示“已移除失效筛选”。读取失败时保留原数据和筛选。切换到另一份文件仍使用左上角“导入工作簿”。

## 历史空白与覆盖率

- 历史表的空白保持缺失，不补成 0；按实际有记录的数值汇总。某组全部没有记录时显示“—”。
- 总ASIN指标卡 = 当前筛选及关注品牌范围内的不同ASIN数量；包含零销量和销量缺失的商品，跨月不重复计数。与活跃ASIN使用相同范围，导出指标同步采用此口径。
- 品牌/属性图表中的样本份额 = 该分组的已知销量/销额 ÷ 当前市场样本的已知销量/销额，不能解释成全市场市占率。
- 数据覆盖率 = 当前关注范围中有该指标数值的 ASIN×月份记录数 ÷ 该范围全部记录数。它是文件内部的记录覆盖率，不代表全市场覆盖率。
- 月度趋势导出包含有效记录数、样本记录数和覆盖率。缺失整个来源月份时提示月份缺失。
- 加权均价仅使用销量和销额均有记录的配对样本计算，避免不一致的分子分母。
- 活跃 ASIN 为所选范围内至少一个月销量大于 0 的商品数量。
- 同比比较去年相同月份，上期比比较紧邻的前一个等长时间段（单月时即环比）。这些变化也会受每期数据覆盖变化影响；没有对应月份、整期无数值或基期为 0 时不计算。
- 普通月度明细格式仍保留原来的严格缺失规则：涉及缺失数值的汇总不计算。

## 重复 ASIN 和关联说明

导入摘要的悬停提示展示实际选用的子表、空白数量、属性关联问题和处理依据。

- 商品属性表中的重复 ASIN 只对应一份历史记录，不能让销量重复计数。
- 若重复行中只有一行的 Amazon 商品链接与 ASIN 一致，而其余行的有效商品链接指向别的 ASIN，使用一致的那一行，并记录原行号和处理依据。
- 无法据链接消除歧义时，相同或互补属性合并；真正冲突的字段标记为“待核对（属性冲突）”，不擅自选择第一行或最后一行。
- 历史销量/销额表出现重复 ASIN 时仍要求先统一口径，不自动相加。父子体重叠统计不能混入，程序不自动合并父子体或进行币种换算。

这些规则只影响看板中的关联视图，不改写原工作簿。

## 导出与产品矩阵

“导出看板与明细”生成 Excel，包含看板图表、当前明细、完整排名、市场趋势、月度份额、指标和统计口径 7 张表。统计口径记录来源、筛选、覆盖和属性关联问题。明细遵循当前搜索与图表定位，图表和指标使用当前市场/关注品牌范围。导出不可覆盖源文件。

“发送到产品矩阵”有选中行时发送所选 ASIN，否则发送当前明细的全部 ASIN。同一商品汇总当前可见月份的已知销量和销额，采用主表特征，并自动打开“产品矩阵 → 自由组合矩阵”。若定位单月，则仅汇总该月。链接形式的图片字段保留，原表中嵌入的图片不经过数据导入保留。

中间工作簿保存在用户配置目录的 `dashboard/matrix-inputs`。工作簿修改后直接点击“重新加载数据源”，无需保存或加载方案。

## 性能与验证

v1.11.3 去掉每次筛选时的默认明细排序，缓存明细列值，按整列执行搜索和分组汇总；保留用户主动点击表头排序的能力。历史缺失口径、份额分母和统计结果保持原有定义。

新增重新加载、选值保留/失效提示、失败恢复、下拉面板高度、固定全选和搜索排序回归检查，相关 36 项及完整 263 项测试通过。用真实工作簿核对全量及属性筛选求和、明暗主题、矩阵发送与源文件哈希。


v1.11.4 趋势图新增范围、零基线、平坦/缺失数据和放大定位检查，相关 40 项测试通过。
