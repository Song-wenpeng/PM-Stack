# 本地备份与恢复（v1.10.16）

在“评论分析 → 设置 → 数据与备份”中操作。评论查询、采集和导入统一使用本地数据库。

## 备份

“立即备份”生成 ZIP 备份包。默认位置为 `%LOCALAPPDATA%\PM Stack\reviews\backups`；可以选择其他目录。选择目录只改变备份存放位置，不移动正在使用的数据库。

备份包含：

- SQLite 评论数据库：评论原文、标签、商品关联、分类、采集记录及旧历史。
- 分析任务记录、每个任务的评论输入快照、模板快照、已生成标签文件及日志。
- 分析记录引用的已生成报告，即使报告保存在其他目录。
- 当前品类模板，以及模型名称、服务地址和主题等少量非敏感设置。
- 版本、创建时间、任务数、缺失文件列表及每个文件的 SHA-256 校验清单。

尚未生成或已丢失的文件会记录在清单中，并在完成日志中提示。API 密钥、云端会话和浏览器会话不会进入新备份，换电脑后需要重新配置模型密钥。销量、产品矩阵等其他模块文件尚未纳入此备份范围。

默认每天首次空闲时自动备份；软件需要保持运行。采集、导入或分析任务正在运行时延后。默认保留最近 10 个自动备份，可调整或关闭。手动备份与恢复前备份不会自动清理；自动备份失败会在日志中提示，当天可手动重试。

## 校验与恢复

列表中可选择备份、校验、恢复或打开备份目录。也可选择其他电脑复制来的 ZIP。恢复前会校验所有文件哈希、数据库完整性和任务路径；不接受不安全路径或高于当前支持版本的数据库。

恢复需确认，因为它会替换当前评论库和分析任务资料。确认后只是暂存并安排恢复；关闭所有 PM Stack 窗口后再次启动时执行。执行前自动生成 `before_restore` 备份，恢复失败时回退当前文件并保留待恢复包。恢复后评论直接从本地加载，分析文件路径重建到当前电脑的用户目录，报告放入 `restored_review_files`。未完成任务可继续分析。

“取消待恢复”可以取消已安排、尚未执行的恢复。

支持旧版 `reviews_backup_*.db`：只恢复评论数据库，保留当前分析任务和报告。这种旧备份本身没有报告和任务资料。

本地默认备份与数据库通常在同一磁盘上。需要跨电脑恢复或防范磁盘损坏时，可把 ZIP 复制到其他磁盘，或者直接选择其他磁盘作为备份目录。

## 云端功能

Supabase 配置、登录、同步按钮和运行依赖已从当前版本剥离，相关技术资料位于“未来开发方向/云端同步”。已有本地数据与旧上传历史保留，但不再自动上传。此次云端数据导出因旧会话恢复失败未完成，无法确认云端独有数据是否全部进入本地。
