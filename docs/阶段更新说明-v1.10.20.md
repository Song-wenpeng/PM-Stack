# PM Stack v1.10.20：本阶段更新

发布时间：2026-10-19。此次汇总 GitHub 上的 v1.10.3 之后至 v1.10.20 的本地开发成果。

## 评论分析与数据管理

- 统一“开始分析、评论库、分析记录”工作流，支持输入与模板快照、继续任务和失败重试。
- 新增品类、提示词编辑与完整预览；新模板用于新任务，已有任务保留原快照。
- 报告问题证据补齐原始负向标签、负向二级类别与原文跳转。
- 本地 SQLite 成为评论主库；移出云端登录、自动同步和相关运行依赖，保留技术源码归档。
- 新增评论库、任务、报告与模板的完整 ZIP 备份，支持校验、每日自动备份、保留策略和下次启动恢复。

## 销量数据与产品矩阵

- 整理单文件/批量销量拆分流程与交互；增加历史销量、销额提取，支持补充 Excel 和写入指定工作簿。
- 使用“商品属性表、销量历史表、销额历史表”等用途名称提示数据来源。
- 优化自由组合矩阵的分组、排序、工作区与导出交互。

## 字段提取

- 支持字段规则与输出要求模板、本次字段勾选、搜索及标签条件筛选；未匹配行不参与提取和补抓。
- 补抓与提取采用独立流水线，商品五点描述与图片地址按 ASIN 缓存。
- 写回保留原行位置、样式、普通嵌入图片及受支持的公式结构，另建“字段提取日志”记录过程。
- v1.10.20 修复断点“无报错即完整”的判断：先恢复已有成果，再检查当前所选字段，仅补缺失项。
- 保留当前表格的有效值、人工修改与历史图片识别日志；兼容旧版断点，并恢复停止、失败行的部分结果。
- 完整产品跳过 AI 与网页补抓；未完整行保留断点并显示缺失信息，同次运行不无限排队。
- 提取与写回统一“未知、未说明”等缺失值规则，数字 0 和已有有效值保持不变。

## 桌面交互与构建

- 顶部横向导航、全宽工作区、明暗主题和 Ctrl+1~4 快捷键。
- 统一固定底部任务栏、就地必填校验、结果打开入口及高级参数折叠。
- 工作表/列名异步读取与搜索选择；长表单独立滚动。
- 移除自适应图表实验模块，保留评论分析、销量数据、产品矩阵、市场规划四个内置模块。
- 使用 Python 3.12+ 独立环境；主程序文件名固定为 PM Stack.exe。

## 下载与升级

- 首次使用：下载本 Release 的 `PM-Stack-v1.10.20.zip`，解压后运行 `PM Stack.exe`；包内含独立更新器和更新通道。
- 手动更新：关闭软件，下载 `PM-Stack.exe`，重命名为 `PM Stack.exe` 后替换原主程序。
- 自动更新：客户端读取 `update.json`，校验主程序大小和 SHA-256 后由更新器替换。
- 模型密钥、数据库和本机配置不包含在分发包中；现有用户数据保存在本地用户目录。

## 验证

- 完整项目测试：230 项通过（Windows / Python 3.12）。
- EXE 启动、矩阵预览、提示词编辑器检查通过；显示版本 v1.10.20。
- EXE 内字段恢复、缺失判断、表格写回与当前测试源码一致。
- 更新清单的版本、大小和 SHA-256 与分发主程序一致。

## 当前限制

- Amazon 验证码、商品不可访问和页面加载超时仍可能导致补抓失败；本次断点修复不代表已消除网页访问问题。
- 无法从现有资料确定的字段会保留缺失，不以猜测值填满；可补充资料后再次执行。
- 另存输出时，继续提取建议选择包含最新结果的表格作为输入；原路径续跑可复用匹配输入与配置的有效断点。
- WPS/Excel 占用或同步冲突导致正式写回失败时，程序会保留 pending 临时结果；确认正式输出完整后再整理旧临时文件。
- 备份覆盖评论与分析任务资料，不覆盖其他模块的外部工作簿。
