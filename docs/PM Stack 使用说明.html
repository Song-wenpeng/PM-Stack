PM Stack 使用说明书

电商数据分析工作台 · 评论 VOC 分析 / 销量数据 / 产品矩阵 / 市场规划
适用版本：V1.10.2  |  更新日期：2026-08-31  |  适用对象：运营、产品同事（无需任何编程基础）

软件简介

PM Stack 是一款 Windows 桌面软件，把日常亚马逊运营/产品分析中最耗时的几类工作做成了「点几下按钮就能跑」的工具：

功能模块帮你做什么是否需要 AI
💬 评论分析AI 逐条阅读评论，提取优缺点、使用场景、用户身份等标签，再归类汇总成分析结论（VOC 分析）需要
📊 销量数据销量 Excel 清洗拆分、ASIN 趋势提取、多条件交叉分析、品牌市场份额占比不需要
🧩 产品矩阵生成使用场景矩阵、销额透视矩阵、品牌×分类图片矩阵（Excel 嵌入商品主图）不需要
🎯 市场规划AI 从商品描述/主图提取结构化字段、细分市场机会得分、类目初筛、数据采集进度部分需要
关于 AI 功能 标注「需要 AI」的功能依赖一个第三方大模型接口（类似 DeepSeek）。首次使用前必须先在「设置」里填入 API Key，详见第二章。不配 API 时，销量数据、产品矩阵等纯数据处理功能仍可正常使用。

一、安装与启动

PM Stack 是免安装的绿色软件，不需要管理员权限，也不写注册表。

  1. 下载并解压：从同事分享的链接下载压缩包，解压到一个你自己电脑上的文件夹（例如 D:\PM Stack 或桌面）。解压后应能看到三个文件：PM Stack.exe、PM Stack Updater.exe、update-channel.json。
  2. 双击 PM Stack.exe 启动。首次启动 Windows 可能弹出蓝色「Windows 已保护你的电脑」提示——这是因为软件没有购买微软代码签名证书，并非病毒。点击 「更多信息」→「仍要运行」 即可，之后不再弹出。
  3. 三个文件始终放在一起：Updater 负责以后自动升级，分开存放会导致更新失败。
注意 请把软件复制到自己电脑本地再运行，不要直接在共享盘 / 网盘同步目录里双击运行，多人占用和断网会导致异常。也建议不要放在中文路径过深的位置。
你的个人配置保存在哪里？ 所有设置（API Key、主题等）保存在 C:\Users\你的用户名\AppData\Local\PM Stack\config.json，其中 API Key 经过 Windows DPAPI 加密，卸载或换目录都不会丢失配置。

二、初始设置（必做）

点击左侧导航栏最下方的 齿轮图标 打开「设置」对话框。

配置 AI 接口（API Key）

AI 功能走「OpenAI 兼容接口」，支持硅基流动（SiliconFlow）、DeepSeek 官方、阿里百炼等服务商。以团队目前使用的硅基流动为例：

  1. 打开 siliconflow.cn 注册账号并充值（评论分析按条数消耗费用，几百条评论大约几毛钱到一两元）。
  2. 在硅基流动后台「API 密钥」页面新建一个密钥，复制 sk- 开头的那串字符。
  3. 回到 PM Stack，打开 设置 → API 配置，填入三项：
    配置项填什么
    API Key刚才复制的 sk-...（输入时显示为圆点，属正常）
    Base URLhttps://api.siliconflow.cn/v1
    Modeldeepseek-ai/DeepSeek-V3
  4. 点击「保存」。窗口右上角徽章变为 「● AI 已配置（未验证）」 即表示已保存；是否真的连通，跑一次 AI 功能即可验证。
安全说明 API Key 使用 Windows 系统级加密（DPAPI）存储在你本机，不会明文写入任何文件，也不会随软件分发给别人——每位同事需要填入自己的 Key（或管理员统一分发的 Key）。

视觉模型配置（仅「市场规划 → 字段提取」需要）

如果你要用「字段提取」功能里的图片识别（让 AI 看商品主图来补全参数），需要一个支持看图的多模态模型：

  • 三项全部留空：默认使用上方主 API 配置，只有主配置的模型本身支持看图时才能用。
  • 单独配置：Vision API Key / Vision Base URL 留空可沿用主配置，Vision Model 填一个视觉模型，如 Qwen/Qwen3-VL-30B-A3B-Instruct（硅基流动平台可用）。

三、界面与通用操作

界面布局

  • 顶部模块导航：评论分析、销量数据、产品矩阵、市场规划横向排列，当前模块以蓝色圆角高亮；右侧是主题切换（月亮/太阳图标）和全局设置。
  • 顶部标题栏：显示当前模块名称和简介，右上角是 AI 配置状态徽章。
  • 中间内容区：每个模块由若干「卡片」组成，每张卡片是一个独立功能，下方黑色区域是运行日志，实时显示处理进度。
  • 底部状态栏：显示 API 配置状态、已加载模块数、当前版本号。

通用操作技巧

操作说明
Ctrl+1 ~ 4快速切换四个模块
拖拽文件所有路径输入框都支持直接从资源管理器把文件/文件夹拖进去，免去手动选路径
输出路径留空几乎所有功能的「输出文件」都可以留空，软件会自动在输入文件旁边生成，并加上约定后缀（如 _AI处理、_拆分结果）
主题切换顶部右侧月亮/太阳图标一键切换深色/浅色，选择会被记住

四、评论分析

评论分析分为“开始分析”“评论库”“分析记录”。默认从“开始分析”进入，添加评论、选择品类即可生成洞察报告。

开始分析

  1. 点击“导入 Excel”或拖入一个/多个 .xlsx 文件。自动识别“内容”“评论内容”等正文列，并显示有效评论数。
  2. 按需点击“调整范围”，勾选要分析的工作表；说明页等不含评论的表会自动忽略。
  3. 选择产品品类，可应用到全部文件，也可逐文件调整。每个文件独立生成报告。
  4. 点击“开始分析”，进入分析记录查看进度。完成后查看主要发现或打开完整 Excel 报告。

报告默认保存到源文件旁，文件名带时间戳。“更多选项”可修改报告位置，或仅提取标签、仅汇总已有标签。原始评论文件不会被覆盖。

评论库

按商品查看评论，可筛选星级和关键词。点击“添加评论”导入 Excel 或在线采集；Excel 默认仅入库。“分析这些评论”会先确认全部匹配评论的范围和品类，确认后直接开始分析，中间文件自动保存。

分析记录

每个文件对应一条记录，保存品类、评论数、时间和状态。完成后可查看主要问题、优点、改进需求，打开报告及所在文件夹。报告中保留维度明细与评论原文证据。

五、评论分析 · 继续任务与设置

运行中可停止任务；重启后从分析记录点击“继续分析”。提取失败时重试未完成部分，成功评论复用断点；汇总失败后直接继续生成报告。任务使用已保存的评论与模板快照。

汇总阶段点击停止时，当前报告仍会完成并保存，后续文件停止。详细日志可展开查看。

页面右上角“设置”提供分析模板导入/导出、并发数、RPM/TPM 以及数据同步与备份。常规分析使用默认参数即可。

📊六、销量数据

无需 AI 对从卖家精灵等工具导出的销量 Excel 做清洗、拆分、趋势分析和市场份额统计。

Tab 1 · 数据清洗

① 单文件销量拆分

把一个总表按 ASIN/子体拆成规整的时间序列数据。输入 Excel 需包含以下列：

必需列说明
ASIN、父ASIN商品标识列
月销量、子体销量销量数据列
月销售额($)、子体销售额($)销售额列，货币符号 $ € £ ¥ 均可自动识别

输出 _销量拆分.xlsx。「批量销量拆分」同理，选一个文件夹即可批量处理里面所有 Excel。

② 数据提取

在「数据提取」页，从逐月拆分文件提取全部 ASIN 的历史销量和销额，并写入指定 Excel 中两个独立的 Sheet。也可用补充数据补齐或修正月份。

  • 源数据：包含逐月 *_销量拆分.xlsx 文件的文件夹；「销量列」「销额列」指定这些文件中的列名。
  • 补充数据：可选的 Excel 文件；「销量Sheet」「销额Sheet」指定其中 ASIN 为行、月份为列的两个宽表。相同 ASIN、月份以补充数据的非空值为准。也可以仅用补充数据提取。
  • 输出文件：选择已有 .xlsx 工作簿或输入新文件路径；其他 Sheet 保留，同名的生成 Sheet 会更新。
  • 生成Sheet：分别填写历史销量和历史销额的 Sheet 名。点击「提取数据」后，两个表均按 ASIN 为行、月份为列生成。

③ 数据修正

发现某条数据异常时，直接修正「指定 ASIN + 指定年月」的销量/销额矫正值。年月格式如 2025-03。保存前会自动生成带时间戳的备份文件，改错了可以找回。

Tab 2 · 交叉属性（多条件筛选趋势）

回答这类问题：「白色 + 塔形 的排插，过去一年销量走势如何？」最多支持 10 个筛选条件动态组合。

  1. 选择 Excel，填写数据 Sheet 名；「元数据 Sheet」留空默认第一个 Sheet。
  2. 选择趋势模式：销量趋势 / 销额趋势 / 销量&均价趋势（双轴）。选后两者需填写「第二数据 Sheet」（销额表）；均价 = 销额 ÷ 销量。界面下方的提示行会标明当前模式哪些 Sheet 必填。
  3. 设定筛选条件数，逐条填写 列名=值。一个条件里多个值用英文逗号，如 颜色=白色,黑色；值留空表示「按这一列分组」（每个值各出一条线）。
  4. 输出路径留空时，文件名由筛选值和分组字段组成，例如 普通排插_三角形_US插口数.png。
  5. 点「生成趋势图」出图；需要原始数字时点「导出数据」（需先填导出路径，且销量、销额两个 Sheet 都要填）。

Tab 3 · 市场占比

按品牌（或任意列）统计月度市场份额占比趋势，回答「这个类目里 Top 品牌各占多少、此消彼长」。

字段说明
分组列名按哪一列统计份额：品牌、线长、颜色、使用场景……都可以
展示 Top N默认 8，范围 2~20；其余合并为「其他」
筛选条件可选，格式 列名=值，多个条件用英文分号 ; 分隔
DPI图片清晰度，默认 200，印刷场景可调 300+
同时输出占比数据表勾选后除图片外再生成一份份额 Excel

🧩七、产品矩阵

无需 AI 把竞品数据整理成可视化的矩阵 Excel（单元格里直接嵌入商品主图），用于竞品盘点和选品汇报。

Tab 1 · 使用场景矩阵

按「使用场景」一列的值分列排布，每个单元格嵌入商品主图 + ASIN + 上架时间。

  • 源 Excel 的 Sheet 需包含 ASIN、商品主图、上架时间 及分组列。
  • 「分组列名」默认 使用场景，可改成其他列；「目标值」逗号分隔，留空 = 全部场景。
  • 输出文件需手动指定路径。

Tab 2 · 销额透视矩阵

两个维度交叉透视，例如「三级分类（行）× 插孔布局（列）」，每个单元格显示销额总和 / ASIN 数 / 平均销额。销额取值有两种方式（二选一）：

方式填法
方式一：元数据取值只填「销额列名」，直接从主表的某一列取销额
方式二：子表格月份取值填「数据子表格」（如 子体销额）+「月份列」（如 2025-12），从子表指定月份取

纵向/横向的「维度值」留空表示全部纳入，也可用筛选条件 列名=值 预过滤。

Tab 3 · 品牌×分类矩阵

以品牌为列、分类为行的图片矩阵，适合多品牌横向对比。单元格内嵌主图 + ASIN + 自定义属性。

字段说明
分类列名 / 品牌列名默认 三级分类 / 品牌
目标品牌必填，逗号分隔，决定矩阵有哪几列
图片列 / ASIN 列默认 商品主图 / ASIN
属性列单元格内追加显示的属性，如 插孔布局,额定功率,价格
排序列 / 排序方式留空按 ASIN 排序；填了排序列后才能选升/降序
父ASIN列 + 销量列 + 变体属性列三件套用于变体合并：同一父体的多个变体只保留销量最高的做代表，并在单元格标注变体差异（如线长、颜色）。不合并则全部留空
上架时间列填入后自动提取年份做新品汇总

🎯八、市场规划

Tab 1 · 字段提取 需要 AI

让 AI 读商品描述文字、看商品主图，把非结构化的 listing 变成结构化字段（如插孔数、线长、材质），是建竞品数据库的第一步。

  1. 选择商品数据 Excel（含商品描述、主图链接等）。
  2. 选择产品类目；类目旁边的 「+ 添加类目」可新建类目，「编辑字段」打开一个表格对话框，可增删字段并编辑每个字段的「文本提取规则」和「图片提取规则」（即告诉 AI 这个字段该怎么认）。
  3. 在「提取字段」区勾选本次要提取的字段（全选/全不选可批量操作）。
  4. 按需勾选「启用图片识别」（需要第二章配置视觉模型；关掉则只读文字，速度更快、费用更低）。
  5. 点「执行提取」。每处理 10 行自动保存一次；点「停止」会在当前行完成后保存退出。

Tab 2 · 机会得分 无需 AI

选择一个装着多个细分市场数据 Excel 的文件夹，自动计算每个细分市场的综合机会得分并输出汇总评分表。评分模型：市场体量 30 分、竞争结构 20 分、价格环境 15 分、新品成长机会 25 分、门槛与热度 10 分。

Tab 3 · 类目筛选 需要 AI

面对成百上千个候选类目，AI 结合公司产品线简介（连接类/墙装类/控制类/能控类/庭院户外类）逐个判断相关性，初筛掉不相关或不可进入的类目。每批 20 个、每 5 批存一次断点，大列表中途中断也不丢进度。

Tab 4 · 数据进度 无需 AI

数据采集（爬虫）配套工具：选择「全部 ID 列表」txt 文件和已爬取文件所在目录，软件比对后输出各品类完成百分比，并生成 missing_ids.txt（还没爬的 ID 清单）。默认按 .png 文件名匹配，可在「文件扩展名」修改。

十、软件更新

  1. 如果管理员配置了更新源，软件启动时会自动检查新版本，发现后弹窗提示，点「是」开始下载。
  2. 下载完成并校验通过后，再次确认，软件自动关闭并由 PM Stack Updater.exe 完成替换、重启，全程无需手动操作。
  3. 旧版本会自动保留为 PM Stack.previous.exe，万一新版本有问题可以改回文件名恢复；确认新版本稳定后可手动删除它。
  4. 更新日志记录在 %LOCALAPPDATA%\PM Stack\updater.log。
如果更新失败 程序会自动回滚到旧版本。反复失败请联系管理员，直接领取最新完整压缩包覆盖安装即可（个人配置在系统目录，不受影响）。

十一、常见问题 FAQ

Q1：双击后 Windows 提示「已保护你的电脑」？

软件未购买代码签名证书导致的正常提示，点「更多信息 → 仍要运行」。如被杀毒软件拦截，请选择信任/添加白名单。

Q2：AI 功能报错「未配置 API」「API Key 无效」？

打开设置检查三项：API Key 是否填了 sk- 开头的完整密钥；Base URL 是否为 https://api.siliconflow.cn/v1；硅基流动账户是否还有余额。Key 有效但提示连接失败时，检查公司网络是否限制了外网 API 访问。

Q3：评论分析跑到一半断了 / 失败了怎么办？

在「分析记录」中选择未完成任务，点击「继续分析」或「重试未完成部分」，会从有效断点跳过已成功条目，只处理失败或未完成的评论。批量分析重新运行也会复用断点。

Q4：日志里出现 429 是什么意思？

表示触发了 AI 服务商的限流（每分钟请求数/Token 数超上限）。评论分析会自动等待重试，一般无需干预；频繁出现就把并发数从 8 降到 4。

Q5：提示「数据源缺少以下列」？

输入 Excel 的列名和软件约定不一致。对照第十章的格式要求检查列名（注意中英文、括号、货币符号），从导数工具导出后不要手动改列名。

Q6：矩阵 Excel 里图片显示不出来？

商品主图必须是可公开访问的图片链接（http/https），本地图片路径无效。另外请联网生成矩阵，图片是生成时实时下载嵌入的。

Q7：点按钮没反应？

看一眼下方日志区：多数情况是缺少必填项或「当前有任务正在运行」。日志区的红色文字会明确告诉你缺什么。

Q8：我的 API Key 安全吗？会被别人看到吗？

Key 经 Windows DPAPI 加密后只存在你自己电脑的系统目录，软件界面只显示圆点，任何导出的文件中都不会包含 Key。

Q9：处理结果文件在哪里？

绝大多数功能默认把结果放在输入文件旁边，文件名带约定后缀（_AI处理、_AI总结、_AI全流程、_销量拆分 等）。

Q10：想要新品类模板 / 新提取字段 / 新功能？

品类评论模板和字段提取规则都可以自定义：评论分析页右上角的设置支持导入/导出品类 JSON 配置；市场规划的字段提取支持在界面里直接「+ 添加类目」「编辑字段」。复杂需求请联系管理员。
